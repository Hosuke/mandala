# 金胎不二 · 兩部曼荼羅引擎

> 絹本曼荼羅是投影，不是結構。結構是：一張圖、兩種遍歷方向、一套變換語義。
> 這個引擎承載結構本身。

瀏覽器打開即是壇城，無須構建、無須安裝、無外部圖片資源——一切尊形皆程序所現。

**線上即入壇 → https://hosuke.github.io/mandala/**

或於本地起任一靜態服務：

```
python3 -m http.server 8000   # 任一靜態服務即可
open http://localhost:8000
```

法義結構論之全文，見 **[docs/法義講義.md](docs/法義講義.md)** ——改架構者請先讀此卷。

## 結構即教義：七層架構

| 層 | 檔案 | 教義對應 |
|---|---|---|
| **不二層** | `js/data/deities.js` | 單一規範圖數據，永不直接渲染。每尊一條記錄；胎藏（`t`）與金剛界（`k`）只是同一節點的兩個面。一條記錄同時持有兩面者，即兩部同體之尊——金胎不二的錨點（大日、五佛對應、普賢即金剛薩埵、觀音即金剛法、文殊即金剛利、虛空藏即金剛寶、彌勒即金剛因）。 |
| **投影層** | `js/layout.js` | 同一圖之兩個布局函數：胎藏＝同心放射（流出之拓撲，共時的）；金剛＝九宮序列（轉換之拓撲，歷時的）。九會中八會是「回響」——同一批節點經各會之**定形**（種字／三昧耶形／尊住杵中／尊捧供養／忿怒尊形）再現；各會之形是其身份之一部，不隨轉相而變，唯成身會隨之。 |
| **相之層** | `js/textures.js` + `js/data/siddham.js` | 一切尊形 canvas 程序生成：月輪、悉曇種字（自 IAST 轉寫即時編譯）、三昧耶形及已核粉本白描。未備已核尊形者退種字，種字亦未核者列尊名；非人身智印以標幟表示。 |
| **遍歷層** | `js/traversal.js` | 上轉門／下轉門：同一回路之二向。金剛界行九會之螺旋（成身→……→降三世三昧耶，及其逆），胎藏行諸環之漲落（中臺→外金剛部，及其逆）。 |
| **行者層** | `js/camera.js` | 俯瞰（觀畫）與入壇（在場）。入壇之際諸尊立起——法曼荼羅轉為羯磨曼荼羅，畫成為空間。 |
| **觀法層** | `js/goso.js` | 五相成身觀（金剛頂經）：坐於成身會壇心，觀心月輪——通達菩提心、修菩提心、成金剛心、證金剛身、佛身圓滿。入觀世界漸隱（內觀），第五相世界復明（出定見世界，諸佛如是我亦如是）。 |
| **講堂層** | `js/data/kodo.js` + `js/samaya3d.js` | 第三投影：東寺講堂立體曼荼羅廿一尊，三輪身 5×3 之陣（自性輪身佛・正法輪身菩薩・教令輪身明王）。依其陣不依其像——佛像國寶，結構公器。三昧耶形升為程序三維法器（`samaya3d.js`，Lathe／Tube／Extrude，matcap 金質），標幟之相入壇即浮現掌前。 |

## 三語

界面與釋義（法語、行狀、觀文）備中・英・日三語（左上切換，localStorage 記之）。日語取文語調，英語取清簡法語體。**壇上之字不譯**——尊名月輪、院會名牌、悉曇種字是圖像之一部，如絹本金泥之題字不隨觀者而變；梵名羅馬字本是通用之層。

## 操作

- **不二滑尺**（底部）：胎藏 ⇄ 金剛之連續形變，諸尊沿極坐標弧線旋入旋出（漩渦收束，非直線穿心）。中點即「不二」——兩部同體之錨點微明可辨；缺一面之尊攝入其部主而隱顯。
- **下轉**：佛成為世界之路。自中心順旋而出，法語隨行。
- **上轉**：眾生成佛之路。自外逆旋而入，同一條路，倒讀。
- **轉相**：法（悉曇種字）→ 三昧耶（線描標幟）→ 大（白描尊形）三相輪轉。數據不動，唯換渲染函數；第四曼（羯磨）由「入壇」成，不在此鈕內。唯成身會與真身隨轉相，餘八會定形。
- **入壇**：第一人稱入於壇中（拖曳環顧，WASD 行步，Esc 出）。標幟之相入壇，三昧耶形現為立體法器浮於掌前。
- **講堂**：羯磨壇——廿一尊飛赴東寺講堂之陣，三輪身五行連線。再按出陣。
- **原典**：開「原典帖」——歷史絹本曼荼羅之投影對照（梵字曼荼羅、金剛界白描卷、兩界佛畫帖單葉、白描圖像稿，皆 CC0 公有領域，附出典）。壇上尊形皆程序所現（零圖片）；此帖所陳乃絹本之投影，正證「絹本是投影，非結構」。獨立成頁，與壇城之零圖片內核物理隔離。
- **西院待審**：開 [兩界待審圖](saiin.html)，按東寺西院本照片的像位布局，備縮放、拖曳、逐席查閱、院會篩選與三語。全部為機助草稿，須人工核定；未辨者標位，千佛帶暫標群像範圍。
- **投花**：閉目擲花，花落何尊即與何尊結緣；結緣之證可下載成卡，緣存於 localStorage，再來復緣。
- **觀法**：五相成身觀之引導序列。輕觸以進，觀無促令；每相一磬，各綴真言。Esc 出觀。
- **磬音**：按「默／音」啟之。颂鉢之聲程序合成（非諧泛音列＋微差拍），五部各韻：點尊一磬、入壇一鐘、換會一響、花落雙磬，底有持誦之鳴。
- **法具欄**（右側）：「具／收」一鈕收展諸鈕；矮屏初即收之，記於 localStorage。
- **點尊**：得悉曇種字、梵名、真言、部族、兩部所在之位；若此尊此相有對應之歷史原典（如大日之種字相），詳情框下方現絹本之圖，附出典與授權，隨轉相而換。

## 尊位凡例

尊位仍為現圖系節選：胎藏 53 面、成身會核心 37 面，另有理趣專屬 8 面；合為 87 個身份。理趣會已列十七席，四印會已列十三席，四印之四波羅蜜與內四供養以標幟表示。已核白描共 44 面；缺形者退種字或尊名，詳情附狀態。種字從既有通行本，新補而未核者留空。

兩界完整現圖以 **[東寺西院曼荼羅（傳真言院曼荼羅）](docs/西院本底本.md)** 為補核底本，尚未完成正式復原。原壇城的環列與九宮是拓撲展布；新增的 **[西院待審圖](saiin.html)** 則另存圖本像位：胎藏 404 項（含 16 標幟／器物），金剛 461 項及 4 處千佛群像區。這是全幅初錄，仍有未辨、漏辨與重辨之可能，不能稱作已核完整尊數。

每席獨立記錄候選身份、圖上位置、可見形態與出典，全部 `pending`。可用同界專筆者只作參照，輪廓草圖只表已讀姿態；未辨處不猜種字或持物。詳見 **[胎藏判讀](docs/西院本胎藏判讀.md)**、**[金剛判讀](docs/西院本金剛判讀.md)** 及 **[尊形補齊盤點](docs/尊形補齊盤點.md)**。

無依賴檢查：`node tools/verify-mandala.mjs`、`node tools/verify-saiin.mjs`（Node.js 22+）。`node tools/export-seat-audit.mjs` 匯出原壇城的 306 個表示席位；與新增西院圖本清單分開計算。

## 技術

Three.js r160（已 vendor）· 原生 ES modules · 零構建 · 壇城零圖片資源（尊形皆 canvas 程序生成）。

唯「原典帖」另載歷史絹本掃圖（`assets/原典/`，CC0），此為投影對照之陳列，獨立於引擎結構之外——非壇城渲染所用。逐尊參攷圖（`assets/參攷-local/`，授權不可分發者）以 `.gitignore` 擋之，永不上線；注冊表（`js/data/genten.js`）缺檔則優雅缺省。
