# 金胎不二 · 兩部曼荼羅引擎

> 絹本曼荼羅是投影，不是結構。結構是：一張圖、兩種遍歷方向、一套變換語義。
> 這個引擎承載結構本身。

首頁即引擎：兩界形變、轉相、入壇、講堂與觀法。胎藏一側自 2026-09-21 起以**席位層**承 **栂尾祥雲原著、吳信如主編《曼荼羅之研究》上下冊（中國藏學出版社，2011 年 6 月）** 所載四百一十二席入壇——同心放射之星空如舊，眷屬如暗星補其位；尊形之閘序守「粉本已核 → 種字 → 尊名」。

依書逐席校對之工作頁在 **[兩界現圖校對頁](book.html)**：每席附名位、形相及書頁出典，畫布上的尊形、標幟均為程序繪製之示意，供內部對照，不是壇城本體。舊址 `engine.html` 自動轉至首頁。

**線上即入壇 → https://hosuke.github.io/mandala/**

或於本地起任一靜態服務：

```
python3 -m http.server 8000   # 任一靜態服務即可
open http://localhost:8000
```

法義結構論之全文，見 **[docs/法義講義.md](docs/法義講義.md)** ——改架構者請先讀此卷。

## 結構即教義：七層架構

| 層 | 檔案 | 教義對應 |
|---|---|---|
| **不二層** | `js/data/deities.js` | 單一規範圖數據，永不直接渲染。每尊一條記錄；胎藏（`t`）與金剛界（`k`）只是同一節點的兩個面。一條記錄同時持有兩面者，即兩部同體之尊——金胎不二的錨點（大日、五佛對應、普賢即金剛薩埵、觀音即金剛法、文殊即金剛利、虛空藏即金剛寶、彌勒即金剛因）。 |
| **席位層** | `js/data/seats.js` + `js/data/book-taizo-*.js` + `js/data/taizo-bija.js` | 一尊可據多席，席繫身份而不等於身份。胎藏四百一十二席自《曼荼羅之研究》各院配置圖逐席轉錄（書據隨席）；有身份錨者繫不二層之尊，一尊數席者以本院為正席（觀自在居中臺，亦現於釋迦・文殊二院——多席歸一身）；餘席立「席身」：唯書載尊名，種字逐席補錄（帶來源、標單源／交叉），查不實則列名（寧缺毋誤）。他日考據既足，席身升為不二層之尊，席號不改。 |
| **投影層** | `js/layout.js` | 同一圖之兩個布局函數：胎藏＝同心放射（流出之拓撲，共時的）；金剛＝九宮序列（轉換之拓撲，歷時的）。胎藏之位以「方周之法」自配置圖化方為圓：席之切比雪夫半徑定其環，方周之位定其角，內外之序與鄰席之序皆存；外金剛部二百三席共一環而交錯內外，席相逼者互推——展布之法，非原畫坐標。九會中八會是「回響」——同一批節點經各會之**定形**（種字／三昧耶形／尊住杵中／尊捧供養／忿怒尊形）再現；各會之形是其身份之一部，不隨轉相而變，唯成身會隨之。 |
| **相之層** | `js/textures.js` + `js/funpon.js` + `js/data/siddham.js` | 月輪、種字、三昧耶形與尊形皆由 Canvas 程序生成。尊形之閘序：粉本已核（`vendor/fenben` 之閘，四十四面）→ 種字 → 尊名；通用二臂不冒充多面多臂異印之尊。`js/book-drawing.js` 之書載通形只供首頁現圖查閱，不入壇。 |
| **遍歷層** | `js/traversal.js` | 上轉門／下轉門：同一回路之二向。金剛界行九會之螺旋（成身→……→降三世三昧耶，及其逆），胎藏行諸環之漲落（中臺→外金剛部，及其逆）。 |
| **行者層** | `js/camera.js` | 俯瞰（觀畫）與入壇（在場）。入壇之際諸尊立起——法曼荼羅轉為羯磨曼荼羅，畫成為空間。 |
| **觀法層** | `js/goso.js` | 五相成身觀（金剛頂經）：坐於成身會壇心，觀心月輪——通達菩提心、修菩提心、成金剛心、證金剛身、佛身圓滿。入觀世界漸隱（內觀），第五相世界復明（出定見世界，諸佛如是我亦如是）。 |
| **講堂層** | `js/data/kodo.js` + `js/samaya3d.js` | 第三投影：東寺講堂立體曼荼羅廿一尊，三輪身 5×3 之陣（自性輪身佛・正法輪身菩薩・教令輪身明王）。依其陣不依其像——佛像國寶，結構公器。三昧耶形升為程序三維法器（`samaya3d.js`，Lathe／Tube／Extrude，matcap 金質），標幟之相入壇即浮現掌前。 |

## 三語

界面與釋義（法語、行狀、觀文）備中・英・日三語（左上切換，localStorage 記之）。日語取文語調，英語取清簡法語體。**壇上之字不譯**——尊名月輪、院會名牌、悉曇種字是圖像之一部，如絹本金泥之題字不隨觀者而變；梵名羅馬字本是通用之層。

## 操作

校對頁（`book.html`）：拖曳移圖、滾輪或按鈕縮放、點尊看放大形相及書頁。可切換胎藏／金剛、院會篩選、尊名搜尋；方向鍵移圖、加減鍵縮放、`0` 復位。下列法具在首頁引擎中使用。

- **不二滑尺**（底部）：胎藏 ⇄ 金剛之連續形變，諸尊沿極坐標弧線旋入旋出（漩渦收束，非直線穿心）。中點即「不二」——兩部同體之錨點微明可辨；缺一面之尊攝入其部主而隱顯。
- **下轉**：佛成為世界之路。自中心順旋而出，法語隨行。
- **上轉**：眾生成佛之路。自外逆旋而入，同一條路，倒讀。
- **轉相**：法（悉曇種字）→ 三昧耶（線描標幟）→ 大（白描尊形）三相輪轉。數據不動，唯換渲染函數；第四曼（羯磨）由「入壇」成，不在此鈕內。唯成身會與真身隨轉相，餘八會定形。
- **入壇**：第一人稱入於壇中（拖曳環顧，WASD 行步，Esc 出）。標幟之相入壇，三昧耶形現為立體法器浮於掌前。
- **講堂**：羯磨壇——廿一尊飛赴東寺講堂之陣，三輪身五行連線。再按出陣。
- **原典**：開「原典帖」——歷史絹本曼荼羅之投影對照（梵字曼荼羅、金剛界白描卷、兩界佛畫帖單葉、白描圖像稿，皆 CC0 公有領域，附出典）。壇上尊形皆程序所現（零圖片）；此帖所陳乃絹本之投影，正證「絹本是投影，非結構」。獨立成頁，與壇城之零圖片內核物理隔離。
- **兩界現圖**：開[校對頁](book.html)，逐席對照名位、形相及書頁。舊[西院照片初錄](saiin.html)另作比較資料。
- **投花**：閉目擲花，花落何尊即與何尊結緣；結緣之證可下載成卡，緣存於 localStorage，再來復緣。
- **觀法**：五相成身觀之引導序列。輕觸以進，觀無促令；每相一磬，各綴真言。Esc 出觀。
- **磬音**：按「默／音」啟之。颂鉢之聲程序合成（非諧泛音列＋微差拍），五部各韻：點尊一磬、入壇一鐘、換會一響、花落雙磬，底有持誦之鳴。
- **法具欄**（右側）：「具／收」一鈕收展諸鈕；矮屏初即收之，記於 localStorage。
- **點尊**：得悉曇種字、梵名、真言、部族、兩部所在之位；若此尊此相有對應之歷史原典（如大日之種字相），詳情框下方現絹本之圖，附出典與授權，隨轉相而換。

## 尊位凡例

主要底本已由西院照片改為《曼荼羅之研究》。胎藏以各院具體圖表錄209內院席、203最外院席；書內正文與圖表不同處在[校正記錄](docs/依書校正.md)說明。同名異院、異會或同方重出者保留獨立席位。

金剛九會依各會名表、配置圖及形像專節分別記錄。成身千佛逐席展開；序號用於辨識圖內席位，不宣稱是千佛經的個別尊名順序。座標保持書內方位與相鄰關係，院幅及間距作顯示縮放，並非歷史絹本的像素摹本。

`js/data/book-*.js` 記每席名位、面臂、坐立、印相、持物及書頁；文字、配置圖、尊容圖與卷首彩版分記來源。`source-checked` 表示與書據已校對，與粉本儀軌正式核定分開。`js/book-drawing.js` 按本席資料繪形（首頁現圖）。正文未載、彩版亦不能辨清的細節列於說明，不轉成讓用戶自行填名位的待辦。

形變演示之胎藏一側以席位層入壇：點任一席，詳情框並陳其院・席次、書據（冊・頁・圖名）、書載形相之摘（面臂・姿・印・持物）與占位狀態（粉本已核／種字待核／席身唯名）。席身之種字自網源逐席補錄（`js/data/taizo-bija.js`：352 席得 188，交叉 34・單源 154，餘列尊名），每條帶引文而標其據，皆屬待核。真實來源之階與掃描本不入庫之律，見 [參考文獻](docs/參考文獻.md)。

無依賴檢查：`node tools/verify-book.mjs`、`node tools/verify-mandala.mjs`（含席位層：四百一十二席、正席之判、席身不冒種字、疏密之律、八方天之方）、`node tools/verify-saiin.mjs`（Node.js 22+）。`node tools/export-seat-audit.mjs` 仍匯出原形變演示的306個表示席位，與書本現圖分開計算。

## 技術

Three.js r160（已 vendor）· 原生 ES modules · 零構建 · 壇城零圖片資源（尊形皆 canvas 程序生成）。

唯「原典帖」另載歷史絹本掃圖（`assets/原典/`，CC0），此為投影對照之陳列，獨立於引擎結構之外——非壇城渲染所用。逐尊參攷圖（`assets/參攷-local/`，授權不可分發者）以 `.gitignore` 擋之，永不上線；注冊表（`js/data/genten.js`）缺檔則優雅缺省。
