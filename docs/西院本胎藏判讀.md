## 点錄方法

全幅先分為上沿、釋迦院、文殊院、中臺／遍知／持明、左右內院、兩側縱院、下沿及外院四邊裁片，以原像素位置逐區點錄。等距大像只在逐行確認實際數目後使用陣列；小眷屬另列，不能由大像矩陣代替。

`u = x / 3033`、`v = y / 3445`，原點為照片左上，向右及向下遞增。`w/h` 是初稿辨識包絡而非精密輪廓：只供點選和布局，不能据之判定手印、持物或像的精確比例。部分近侍／外院密集群像的包絡會重疊，人工應逐席覆核中心、範圍及是否為獨立人像。

院名取既有資料契約。照片左方縱帶暫配地藏院，右方縱帶暫配除蓋障院。左右皆指觀畫者視角，不將此直接換算成儀軌南北。中臺候選名位參照 [MIKKYO21 中臺八葉院文字](https://www.mikkyo21f.gr.jp/mandala/mandala_taizoukai/01.html) 的上／右／下／左及四隅描述，再與照片對位；此參照不是西院本逐尊核定表。

## 未核項與辨識邊界

1. **尊名**：中臺八葉、智印、般若、不動、釋迦、文殊、虛空藏、千手觀自在等只附候選；其餘不按異本名錄的順序自動配席。相同尊名可出現於不同席，不以尊名去重。
2. **面臂與持物**：只在大像清楚時記 `heads: 1` 或 `arms: 2`；不清即 `null`。多面多臂大像只記可見「多面／多臂」，不由尊名逆推千臂或確切面數。
3. **微小眷屬**：蓮華院右緣小像、金剛手院左緣小像緊貼院界，值得逐一放大；初稿依局部可見身形列席。釋迦中央門形上端的獸首與文殊中央三器未當作人像。
4. **外院**：動物坐騎與其上尊像暫合一席；門的獸首、梁柱和純花紋不另列尊。孤立頭像、飛行像的身分及是否應列獨立儀軌席仍待核。
5. **種字**：本幅是尊形／標幟圖。未見清楚字形，不新增任何種字，更不將別本通行種字標成本幅轉錄。
6. **圖像權利**：Commons 標記 Public Domain，專案仍將全幅和裁片限於本地參攷；待審資料不攜照片，也不把照片引入主曼荼羅 canvas。

人工核定時應至少覆核：同本、院界、圖上中心、候選名、面臂、持物、種字是否實見，以及相鄰小像是否漏列或重列。審核完成前不得將 `reviewStatus` 提升，也不得將這些候選送入既有尊形庫的已核准上壇閘門。
