# 依《曼荼羅之研究》校正兩界現圖

2026-09-20。用戶改定以栂尾祥雲原著、吳信如主編《曼荼羅之研究》上下冊為準，取代先前以東寺西院照片為唯一底本。用戶已授權機助讀圖及程序造像草稿；查書、判別名位與實作由開發者完成，不要求用戶逐個空位提供答案。

## 版本與查讀範圍

中國藏學出版社，2011年6月第1版、第1次印刷，ISBN 978-7-80253-355-4。上冊PDF正文頁 = 印刷頁 +29，下冊 = 印刷頁 −347。纸面頁碼與PDF頁分別記錄。

按用戶「抓重點」指示，查讀胎藏內院p121–231、最外院p232–262；金剛成身構造、尊容、外金剛部及附圖p283–352；下冊各會形像、配置與名表p360–523，回看相關正文及卷首彩版。此為針對補圖的查讀，不宣稱已通讀全書。

兩冊PDF、掃描頁及OCR暫存只留本機，不入庫、不隨站發布。新增資料為尊名、圖式座次、形相事實、簡短考據及頁碼；Canvas全為原生幾何，未貼入書籍圖片。

## 名位與形相分別記錄

- `source`：名位所據書冊、印刷頁、PDF頁及章節。
- `layoutSource`／配置圖號：坐次及原圖序號；同名重出仍保留獨立席。
- `iconographySource`：面臂、持物、姿態所據的個別圖或卷首彩版。
- `observation`：實際已查清的可繪形相；未載細相不由別尊或別會推入。
- `reviewStatus: source-checked`：書據已對照，與vendor粉本的儀軌正式核定分開，未改其核定名單。

頁內不再一律顯示「未辨尊／待人工覆核」。名位有證即列書載名號及相對坐次，能讀出的尊容即繪程序形相。局部未明只影響該字段，詳情保留實際界限。

## 顯示

依書現圖頁具縮放、拖曳、名錄、院會篩選及逐尊放大形相；2026-09-22 起定為內部校對頁 `book.html`，首頁 `index.html` 復為引擎（形變、轉相、講堂及觀法，胎藏席位自席位層入壇，書載通形不入壇）。`saiin.html`保留舊照片初錄作比較，不再充任主要底本。

全幅將各院／會配置圖縮放到共同視框，保持名位、方位及相鄰關係。胎藏東上、南右、西下、北左；金剛西上、北右、東下、南左。間距經顯示排版，並非原畫像素摹寫。

主名錄合胎藏412席、金剛1481席；後者包含支輪四大神及其標幟。四印會另有8項外角、門口莊嚴，繪入畫面而不加算尊位。形變演示仍是原有代表尊拓撲，全數席位由首頁現圖提供。

每筆按面臂、坐立、僧相／冠飾、持物、手印、乘座及各會圖式分別生成。種字未因補形新增猜測轉錄。程序線描供學習及驗收，正式造像核定另由人工，不阻止書據已明的資料與畫面落實。

本次繪製結果：1506席按已錄面臂、姿態繪人物，188席繪非人物標幟；171席只繪可確認的局部，未明臂數或姿態不補猜；28席已有名位與書據，但現有掃描仍不足定尊容，保留名號（胎藏24小眷屬、金剛降三世4明妃）。此為具體圖像資料界限，不是把查名、查坐次交回用戶。
