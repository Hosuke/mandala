# 書式金剛九會考據與資料邊界

本次據用戶所供《曼荼羅之研究》中文上下冊掃描，作有頁碼可查的機助整理。題名頁及版權頁所載為栂尾祥雲原著、吳信如主編，中國藏學出版社2011年6月版。書圖及書中所論「現圖」是此次名位、形相的主要依據；東寺西院照片仍可參照，不能把此書式整理稱為照片逐像復原。PDF只在本機選頁渲染、OCR及閱讀，未入庫、未外傳。

資料見 `js/data/book-kongo.js`。`identityStatus: text-attested` 表示名字或群名有書據；`reviewStatus: source-checked` 表示已讀核相應文字／圖版，並不宣告宗教上的正式核定。`null` 表示書文或所讀圖版未足以確定，與「未查書」不同。

## 頁碼與實際讀法

- 上冊印刷頁 + 29 = PDF頁。例如印317 = PDF346、印343 = PDF372。
- 下冊印刷頁 − 347 = PDF頁。例如印371 = PDF24、印500 = PDF153。
- 主讀上冊283–285、307–334的形相及外金剛部比較，342–352的編號圖、名表及尊形圖。
- 下冊主讀360–379（三昧耶）、385–388及392–401（微細）、413–418及422–432（供養）、442–447及451–456（四印）、461–464（一印）、468–482（理趣）、487–505（降三世）、506–522（降三世三昧耶）。以名表、位圖、現圖比較及專圖為主，未作全書756頁逐頁掃描。
- 再核卷首彩版上PDF6全九會、PDF11成身會（均無印碼），以及下391、422、495的逐會全圖。成身外二十天逐邊可讀一面二臂坐相，已填入；其餘會各從自己的圖讀取可見頭與坐姿，未直接移植成身的總臂數。
- OCR只供定位；關鍵名表、欄位歸屬、位圖及形相均回看掃描。簡體轉繁體不改名義；例如書印「金剛推天」保留推字，「英惑」以熒惑正名並保留書用字異名。

每席的 `source.page/pdfPage` 是直接身份來源，`positionPage/positionVolume` 是位置來源；`iconographyPage/iconographyVolume` 和 `figurePage/figureVolume` 分別是形相文字、圖版。`references` 保存跨冊的補充依據。不能把一個頁碼當作該席所有細節的共同來源。

## 方位、座次及示意排布

全圖為上西、下東、左南、右北。上342及下370、392、423、451、475、497、513的位圖皆可直接查。中央五尊按中、下、左、上、右排列；四方月輪的第一親近位皆朝向中央，另三親近位按各方編號取位，未把每輪生硬複製同一旋轉。

賢劫十六尊的起數法，下365–366明記：東方從對面右方起，南方從下起，西方從對面左方起，北方從上起。程式轉為畫面下邊右至左、左邊下至上、上邊左至右、右邊上至下。下370等位圖西邊相鄰兩席重印50，據371等名表50無量光、51賢護校正第二個為51；不保留兩個50造成漏尊。

成身千佛每方250，分兩段、每段25列×5行，避開門與隅供養。此為1000個可點選的書式規整席，並非量得西院照片1000個像心。名字「賢劫千佛・第N席」是本站圖內序號，不冒稱經典佛名。合掌依上317「東寺高雄本」的明文；共同佛身是群像示意，不以序號認定某一個原像身份。

## 各會的形相差別

成身三十七尊：上309說現圖與《秘藏記》大體一致，故上310–316比較表取現圖／《秘藏記》欄，面臂坐相再據344–351專圖。尤其金剛語依314、347持如來舌，不能沿舊鈴筆。成身四大神上352有專圖，皆一面二臂承托半身；不以一般坐佛補其下半身。其餘五個大會的同名38–41在各自現圖中為蓮瓣圓輪（下369、391、422、495、512），已分會改為symbol，未把成身半身遍套。

三昧耶：下360以下把尊形轉為標幟，372–379逐圖可查。金剛愛是並列二金剛，不因人物持箭就畫箭；嬉為金剛杵、舞為羯磨，不能只據名字猜姿勢。四大神位置在369現圖為蓮瓣圓輪。書364對東寺阿閦疊金剛明言橫五股杵上豎杵；降三世三昧耶509又稱同式為橫三股。資料逐會保留各段說法，這是本書文字差異，不能抹平為同一精確股數。

微細：下387明言現圖尊容與成身相同而畫於金剛杵內，故三十七尊保留其身形、印物，加 `enclosure:'vajra'`；394–401專圖可對。未挪用《五部心觀》胸前標幟、定印的另一種畫法。

供養：下417特別比較本經、《五部心觀》和現圖。現圖四波羅蜜以外仍為男尊，不能把全會改成女尊。418及425–432示32菩薩雙手捧蓮承本標幟，設 `offering:true`；五佛實圖仍結本印，大日425作無冠佛身智拳，其餘四佛426–429亦非捧蓮。正文泛說「諸尊」須與這些實圖並讀，故沒有把五佛一律改作供物姿勢。

四印：451的1、6–9是人身，2–5、10–13是器形。452–454為五人物圖；尤其業菩薩454持羯磨杵，不是成身會的合掌舉頂。455–456為八器形。

一印：下464現圖只有智拳大日一尊，作寶冠菩薩形。以本會明文立資料，不因同名就任選胎藏法界定印。

理趣：475有完整17尊座位與名表，476–482有全體專圖，皆可讀一面二臂坐相。中央薩埵擲杵持鈴；欲持花箭、觸抱杵、愛持摩竭魚幢、慢雙拳腰。四女尊的名位已確：意生、計里吉羅、愛樂、意氣；479–480小持物保守記花形、蓮華器、燈形、盤形，不把不清楚的細物強說成某一儀軌法器。

降三世：下489中央大日、四波羅蜜同成身；491–492只有阿閦前之金剛薩埵成忿怒降三世相，其餘四佛及親近尊結交叉忿怒拳。500–503可核一面二臂坐形；未挪用493慶喜藏釋「諸尊立姿」的另一傳承。內四供養504仍如成身，外四供養、四攝、賢劫尊依492改忿怒拳持本標幟。圖旁小三昧耶形視作伴置標示，未加算尊位，亦不誤放到人物掌中。

降三世薩埵500可見三面、八臂、站姿踏二天；487–496所讀正文未明言其**總面數**。493的「四面」是慶喜藏釋的毗盧遮那，不能移作薩埵證據。資料故填 `visibleHeads:3`、`heads:null`、`arms:8`。繪圖可畫所見三面八臂，而詳情須保留總面數未由此書核定的差別。

降三世三昧耶：下506–509與515–522另核。大日制底下橫三股杵、四佛主標幟下亦有橫杵，薩埵516為羯磨形；寶波羅蜜515作輪，不能把七會無差別借成身尊形。

## 降三世四隅的書內異說

下494正文先述四明王之說，繼而明判以東南陪羅嚩、西南吉祥天、西北辯才天、東北僑履四明妃為是，並批評四明王說。498的名表卻在78–81列金剛藥叉、軍荼利、大威德、不動。497位圖只畫1–77，未提供這末四名的逐席編號位置。

本次主資料從正文，四明妃按494所記方隅定位；`alternativeNames` 保存498四明王名表的異說。名表並未證明其四名與四隅的一一配位，欄位中的同次列置只供對照，**不得視為四明王各自方位核定**。兩說共占四個待校身份席，絕不加為八尊湊數。其面臂、姿勢、持物沒有此段實據，維持空值。

## 可直接實作與仍須避免的推論

可直接依本檔畫：已書核名位、成身37形及外20天坐像、各會印相差別、三昧耶標幟、微細金剛外框、供養承蓮、理趣17形、降三世可見面臂、承托半身，以及千佛共同合掌示意。其餘外天／賢劫席有可見頭、坐輪廓、名字與本標幟，應畫已有依據的部分並指出缺少的總面臂，不因缺一個數字就把整席說成「未辨」。

不得由本資料宣稱：逐像復原西院照片；圖內千佛序號即經名；四女尊小持物的細節已全部判清；降三世薩埵總共只有三面；四明王名表已與四角一一定位；`source-checked` 即人工終審。未將宗教正式核定權改為機器，亦未以待人工為由停下有書可查的名位、印相工作。
