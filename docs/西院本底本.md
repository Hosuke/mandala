# 東寺西院本：底本及逐席核對

2026-09-20，用戶指定兩界完整現圖以 **東寺西院曼荼羅（傳真言院曼荼羅）** 為準，並授權製作機助待審稿。機讀識別存於 [`js/data/edition.js`](../js/data/edition.js)，鍵為 `toji-saiin`。新增 [`saiin.html`](../saiin.html) 供逐席查閱；正式核定仍由人工。

## 物件識別

| 欄位 | 已核資料 |
|---|---|
| 正式登錄名 | 絹本著色両界曼荼羅図〈／（伝真言院曼荼羅）〉 |
| 文化庁物件 ID | `201/95` |
| 指定號 | `00092(00)` |
| 員數 | 2 幅，胎藏界與金剛界 |
| 時代 | 平安時代・9 世紀 |
| 所有者 | 宗教法人教王護国寺 |
| 國寶指定日 | 1953-11-14 |

正式名、號碼、員數、所有者與指定日依[文化庁國指定文化財資料庫](https://kunishitei.bunka.go.jp/heritage/detail/201/95)；九世紀年代與「西院」別名依[東京國立博物館 2019 年東寺展](https://www.tnm.jp/modules/r_free_page/index.php?id=1938&lang=ja)。[東寺官方寺寶頁](https://toji.or.jp/treasure/)以「西院本曼荼羅（伝真言院曼荼羅）」收錄此件。

西院本須與東寺甲本、乙本、高雄曼荼羅及後世通行現圖分別。通行院會名、尊數與儀軌可供比對，不能因此推定原圖每席身份與坐次相同。

## 西院圖本待審清單

[`saiin-taizo.js`](../js/data/saiin-taizo.js) 初錄 404 項，覆蓋十二院，其中 16 項為標幟、器物或塔；[`saiin-kongo.js`](../js/data/saiin-kongo.js) 初錄 461 個逐席項與 4 處千佛群像區，覆蓋九會。合計 869 條記錄不是 869 尊，更不是完整性驗收數。

每條有獨立 `seatId`、界、院／會、標準化圖上中心及包絡、候選 `canonicalId`、可見形態、判讀說明及出典。相同尊重現仍分席，沒有資料的身份不借同名拼接。全條 `reviewStatus: 'pending'`；群像區 `memberCount: null`，不把整區算作一尊。

待審 Canvas 只畫程序線條。既有同界專筆是參照形，不等於本幅已核；輪廓草圖只示已讀面臂及坐立，未知者留標記。沒有新增或猜補悉曇種字。詳細判讀、計數與未竟見[胎藏紀錄](西院本胎藏判讀.md)、[金剛紀錄](西院本金剛判讀.md)。

## 現有席位交接表

執行以下命令，從目前引擎匯出待核清單：

```sh
node tools/export-seat-audit.mjs > /tmp/mandala-saiin-seat-audit.json
```

目前應有 **306 個表示席位**：胎藏 53，金剛九會 253。此數只計現行引擎，不是西院本總尊數，也不含講堂廿一尊。

每個表示席位有獨立鍵；同尊跨會不去重。表中保留現行尊名、表示身份、院／會、相別、粉本狀態與引擎拓撲位置，供逐筆尋回程式。底本席號、底本位置及名位出典先留 `null`，西院本覆核狀態為 `pending`。

既有粉本的 `verified` 只表示通過原粉本閘，**不等於** 已核西院本該席之持物、印相、身色與坐姿。降三世會的換身身份另行列出，不把它當作靜相金剛薩埵。相別為標幟者亦不改計成人身尊像。

核定一席至少須備：

1. 本件胎藏／金剛圖幅、院／會與可重尋的圖版席號。
2. 尊名及身份出典；同名重出分席保存。
3. 坐次或圖版位置出典，並註明觀圖方向；圖面坐標與儀軌東西方向分記。
4. 本席所現之相、種字及尊形依據；未核欄位留空。
5. 人工覆核記錄及對應可上壇的粉本鍵。

完整新增席位仍須由底本編目建立；此工具不把現有 306 席當作全圖全集，也不會將交接表自動匯回壇城。

## 圖像與覆核界線

本輪納入事實編目、獨立程序線條及連結；參照照片與分析裁片僅存於受 gitignore 排除的本地路徑，未入庫亦未載入 Canvas。[東寺官網](https://toji.or.jp/treasure/)聲明不得擅用、轉載圖文；[東京國博 2019 廣報圖申請書](https://www.tnm.jp/uploads/r_press/FAX_208.pdf)所附圖像另限該展報導，不能當作本專案可分發切尊素材。
